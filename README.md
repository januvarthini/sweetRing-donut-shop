# SweetRing Gourmet Doughnut Bakery

Responsive frontend donut shop website using HTML5, CSS3, Tailwind CSS and vanilla JavaScript.

## Features
- Responsive design
- Product catalog
- Search, category/flavor/price filters
- Sorting
- Product gallery
- Cart and quantity controls
- LocalStorage cart and favorites
- Order form validation
- Date/time selection
- Dark/light mode
- RTL/LTR support
- Reviews, offers, location and contact sections

## Run
Open `index.html` in a browser. The project uses CDN resources for Tailwind CSS, Font Awesome and Google Fonts, so internet access is recommended.

## Structure
- `index.html`
- `css/style.css`
- `js/products.js`
- `js/filters.js`
- `js/cart.js`
- `js/gallery.js`
- `js/form.js`
- `js/theme.js`
- `js/main.js`
